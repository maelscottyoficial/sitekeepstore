# Project Summary
The Keep Store project is a cutting-edge web application aimed at improving the shopping experience for electronic products and accessories. It boasts a sleek dark-themed interface and responsive design, featuring real-time product searches and a functional shopping cart. Recent updates include enhanced images in the Hero section's carousel, improved shopping cart capabilities, and a newly implemented checkout page with real-time form validation for a seamless purchasing process. Additionally, clicking the "KeepStore" logo now redirects users back to the homepage from any page.

# Project Module Description
The project consists of several functional modules:
- **Header**: Displays the logo, navigation links, social media icons, and a search modal. Now redirects to the homepage when the logo is clicked.
- **Hero**: Features a sliding carousel with dedicated product banners showcasing key products.
- **Categories**: Showcases different product categories with icons and links to dedicated category pages.
- **ProductGrid**: Displays products, including promotional and best-selling items, with "Add to Cart" functionality.
- **PromoBanners**: Highlights special promotions for specific products.
- **Benefits**: Lists customer benefits like support, warranty, secure payment, and fast delivery.
- **Footer**: Contains store information, links to pages, and a newsletter subscription option.
- **SearchModal**: Allows users to filter products by name in real-time with instant results displayed.
- **ProductPage**: Displays product details with a gallery of multiple images, including clickable thumbnails and navigation arrows. Now includes functionality to add products to the cart.
- **CategoryPage**: Displays products filtered by category with a responsive grid layout.
- **Checkout**: New module that allows users to finalize their purchases with a personal data form, order summary, and payment options. It now includes real-time validation for fields such as email, CPF, and card number, as well as automatic address lookup via CEP.
- **ScrollToTop**: Resets scroll position to the top when navigating to product pages.
- **PageTransition**: Provides a smooth fade-in animation when navigating between the homepage and product pages for a more fluid experience.
- **CartContext**: Manages the shopping cart state, including add, remove, and update operations.
- **CartDrawer**: A slide-out drawer that displays cart items and allows quantity adjustments, now includes functionality to navigate to the checkout page.

# File Description Inventory
- **README.md**: Project overview and setup instructions.
- **components.json**: Configuration for components used in the project.
- **eslint.config.js**: ESLint configuration for code quality checks.
- **index.html**: Main HTML file for the application.
- **package.json**: Project dependencies and scripts.
- **postcss.config.js**: Configuration for PostCSS processing.
- **src/**: Contains the main application source code, including the updated Product page, new Cart functionality, and the Checkout page with real-time validation.
- **public/**: Static assets like images and icons.
- **prerender/**: Scripts for generating static pages for blogs.
- **image_manifest.json**: Updated to reflect the new dedicated images for the Hero component.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS
- **Build Tools**: Vite
- **State Management**: React Context for the shopping cart
- **Linting**: ESLint
- **Styling**: PostCSS, Tailwind CSS

# Usage
To install dependencies, run:
```
pnpm install
```
To build the project, execute:
```
pnpm run build
```
To run lint checks, use:
```
pnpm run lint
```

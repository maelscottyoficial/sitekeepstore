# Project Summary
The project is a web application designed to manage customer orders for an e-commerce platform. It allows users to view their purchase history and order statuses while providing a seamless interface for tracking orders and managing purchases. The application integrates with Atoms Cloud for secure data storage and retrieval, enhancing user experience through features like a custom login modal for improved authentication. Recent enhancements include the implementation of an admin panel for managing products and orders.

# Project Module Description
The project consists of several functional modules:
- **Backend**: Manages order processing, user authentication, and database interactions.
- **Frontend**: Provides the user interface for order tracking, product management, and admin functionalities.
- **APIs**: Facilitates communication between frontend and backend services.

# File Description Inventory
- **app/backend/**: Contains server-side code for handling requests and managing data.
- **app/frontend/**: Contains client-side code for rendering the user interface and handling user interactions.
- **assets/**: Stores images and other media used in the application.
- **app/frontend/src/components/Header.tsx**: Updated to include a link to the admin panel.
- **app/frontend/src/components/LoginModal.tsx**: Modal component for user authentication.
- **app/frontend/src/components/AdminLayout.tsx**: Layout component for the admin panel.
- **app/frontend/src/pages/AdminProducts.tsx**: Page for managing products, including CRUD operations.
- **app/frontend/src/pages/AdminOrders.tsx**: Page for managing orders, allowing status updates and viewing order details.

# Technology Stack
- **Frontend**: React, TypeScript, Vite
- **Backend**: Python, FastAPI, Alembic for database migrations
- **Database**: Atoms Cloud for order data storage
- **Deployment**: AWS Lambda for serverless functions

# Usage
1. **Install Dependencies**:
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
   - Navigate to the backend directory and run:
     ```
     pip install -r requirements.txt
     ```

2. **Build the Project**:
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend server:
     ```
     python main.py
     ```
   - Start the frontend development server:
     ```
     pnpm run dev
     ```

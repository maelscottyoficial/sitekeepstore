# Project Summary
The project is a web application designed to manage customer orders, allowing users to view their purchase history and order statuses. It integrates with Atoms Cloud for backend functionalities, enabling secure data storage and retrieval of orders. The application aims to enhance user experience by providing a seamless interface for tracking orders and managing purchases, with recent updates including improved user authentication and navigation features.

# Project Module Description
The project consists of several functional modules:
- **Backend**: Handles order management, user authentication, and database interactions.
- **Frontend**: Provides the user interface for order tracking, checkout processes, and user authentication.
- **APIs**: Facilitates communication between the frontend and backend services.

# File Description Inventory
- **app/backend/**: Contains server-side code for handling requests and managing data.
- **app/frontend/**: Contains client-side code for rendering the user interface and handling user interactions.
- **assets/**: Stores images and other media used in the application.
- **app/frontend/src/components/Header.tsx**: Updated to include user avatar and dropdown menu for authentication options.

# Technology Stack
- **Frontend**: React, TypeScript, Vite
- **Backend**: Python, FastAPI, Alembic for database migrations
- **Database**: Atoms Cloud for order data storage
- **Deployment**: AWS Lambda for serverless functions

# Usage
1. **Install Dependencies**:
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
   - Navigate to the backend directory and run:
     ```
     pip install -r requirements.txt
     ```

2. **Build the Project**:
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend server:
     ```
     python main.py
     ```
   - Start the frontend development server:
     ```
     pnpm run dev
     ```

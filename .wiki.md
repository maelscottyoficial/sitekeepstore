# Project Summary
The Keep Store project is an innovative web application designed to provide a seamless shopping experience for electronic products and accessories. It features a modern dark-themed interface with a responsive layout, showcasing categories, promotions, and best-selling items. The application enhances user engagement through an intuitive design, real-time product search functionality, and a variety of product offerings.

# Project Module Description
The project consists of several functional modules:
- **Header**: Displays the logo, navigation links, social media icons, and a search modal.
- **Hero**: Features a promotional banner for highlighting key products.
- **Categories**: Showcases different product categories with icons.
- **ProductGrid**: Displays products, including promotional and best-selling items.
- **PromoBanners**: Highlights special promotions for specific products.
- **Benefits**: Lists customer benefits like support, warranty, secure payment, and fast delivery.
- **Footer**: Contains store information, links to pages, and a newsletter subscription option.
- **SearchModal**: Allows users to filter products by name in real-time with instant results displayed.
- **ProductPage**: Displays product details with the layout updated to show the product image below the title.

# File Description Inventory
- **README.md**: Project overview and setup instructions.
- **components.json**: Configuration for components used in the project.
- **eslint.config.js**: ESLint configuration for code quality checks.
- **index.html**: Main HTML file for the application.
- **package.json**: Project dependencies and scripts.
- **postcss.config.js**: Configuration for PostCSS processing.
- **src/**: Contains the main application source code, including updated Product page layout.
- **public/**: Static assets like images and icons.
- **prerender/**: Scripts for generating static pages for blogs.

# Technology Stack
- **Frontend**: React, TypeScript, Tailwind CSS
- **Build Tools**: Vite
- **State Management**: React Hooks
- **Linting**: ESLint
- **Styling**: PostCSS, Tailwind CSS

# Usage
To install dependencies, run:
```
pnpm install
```
To build the project, execute:
```
pnpm run build
```
To run lint checks, use:
```
pnpm run lint
```

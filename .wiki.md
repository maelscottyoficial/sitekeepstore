# Project Summary
The project is a web application designed for managing customer orders within an e-commerce platform. It allows users to view their purchase history, track order statuses, and manage purchases efficiently. The application leverages Atoms Cloud for secure data storage and retrieval, enhancing user experience through features like a custom login modal. Recent updates have introduced an admin panel for comprehensive product and order management, along with a new settings page for integrating Mercado Pago payment processing.

# Project Module Description
The project consists of several functional modules:
- **Backend**: Manages order processing, user authentication, and database interactions.
- **Frontend**: Provides the user interface for order tracking and admin functionalities.
- **APIs**: Facilitates communication between frontend and backend services.

# File Description Inventory
- **app/backend/**: Contains server-side code for handling requests and managing data.
- **app/frontend/**: Contains client-side code for rendering the user interface and handling user interactions.
- **assets/**: Stores images and other media used in the application.
- **app/frontend/src/components/Header.tsx**: Includes a link to the admin panel.
- **app/frontend/src/components/LoginModal.tsx**: Modal component for user authentication.
- **app/frontend/src/components/AdminLayout.tsx**: Layout component for the admin panel.
- **app/frontend/src/pages/AdminProducts.tsx**: Page for product management with full CRUD functionality.
- **app/frontend/src/pages/AdminOrders.tsx**: Page for managing orders, allowing status updates and viewing order details.
- **app/frontend/src/pages/AdminSettings.tsx**: New page for configuring Mercado Pago API keys.

# Technology Stack
- **Frontend**: React, TypeScript, Vite
- **Backend**: Python, FastAPI, Alembic for database migrations
- **Database**: Atoms Cloud for order data storage
- **Deployment**: AWS Lambda for serverless functions

# Usage
1. **Install Dependencies**:
   - Navigate to the frontend directory and run:
     ```
     pnpm install
     ```
   - Navigate to the backend directory and run:
     ```
     pip install -r requirements.txt
     ```

2. **Build the Project**:
   - For the frontend, run:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend server:
     ```
     python main.py
     ```
   - Start the frontend development server:
     ```
     pnpm run dev
     ```
